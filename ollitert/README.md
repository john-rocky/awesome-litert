# OlliteRT model source

45 LiteRT-LM chat models from [litert-community](https://huggingface.co/litert-community) for [OlliteRT](https://github.com/NightMean/OlliteRT), an Android app that serves a model on the phone over an OpenAI-compatible API.

1. In OlliteRT, open Settings → Model Sources → + → From model list URL (.json).
2. Paste `https://raw.githubusercontent.com/john-rocky/awesome-litert/main/ollitert/models.json`.
3. Open the Models tab, download a model and tap Start Server.

Every file below loaded and answered on LiteRT-LM 0.16.1, the runtime in OlliteRT 0.9.7-beta.1, on a Mac CPU. Six of them also ran through OlliteRT 0.9.7-beta.1 on a Pixel 11 Pro: SmolVLM2-500M, sarashina2.2-0.5b-instruct-v0.1, Spark-X2.6-1.7B, PaddleOCR-VL-1.6 and DeepSeek-R1-Distill-Qwen-7B on the GPU, MNN-Pocket-0.3B on the CPU. The Runs on column comes from the Android records on each model card, or from the row's note where the app's runtime is the limit. The list sets `minAppVersion` to 0.9.7. Generated by [`make_ollitert_source.py`](make_ollitert_source.py).

Some models think before they answer. OlliteRT returns that text inside `content` as `<think>…</think>`. It stops a request after 120 seconds by default; for a large model or long thinking, raise Chat completions timeout under Settings → Advanced Settings.

## Not listed

- **Models with recurrent state** (LFM2 and LFM2.5, Qwen3.5, Falcon-H1, Zamba2, granite-4.0-h and others). OlliteRT keeps one engine and opens a new conversation for each request. On LiteRT-LM 0.16.1 such a model carries its state into the next conversation ([LiteRT-LM #3165](https://github.com/google-ai-edge/LiteRT-LM/issues/3165)), so an earlier request can change a later answer.
- **Files too large for a phone**: Qwen2.5-VL-72B, Muse-Glimmer-30B and Qwen3-30B-A3B (over 20 GB each).
- **Unlimited-OCR-2**: it takes no prompt and expects a padded page image, so a chat request gets no useful answer.
- **SmolLM3-3B**: on a Pixel 11 Pro GPU its thinking fell into repetition on a simple question, and another answer ended in garbled text.
- **Olmo-3-7B-Think**: on a Pixel 11 Pro it generated about 4 tokens per second, so its thinking alone passed OlliteRT's 120-second limit on a request.
